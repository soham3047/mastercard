# Frontend — Person D

React + Vite dashboard: transaction graph (ring/star highlighted),
persistence diagram, RPS panel, plain-language explanation, round counter
with bottleneck-distance trend, decoy-density slider, cross-bank panel.

A minimal Vite+React skeleton is checked in already (`package.json`,
`index.html`, `src/main.jsx`, `src/App.jsx`) so D2 can start wiring
components immediately.

## Run

```bash
npm install
npm run dev
```

If you'd rather regenerate the scaffold from Vite's own template instead of
the hand-written one here:
```bash
npm create vite@latest . -- --template react
```

Log progress in `PROGRESS_D.md` (shared with `../backend/`).
